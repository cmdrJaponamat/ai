## Key Commands

- Проверить состояние репозитория:
  - `git -C ~/ai status`
- Зафиксировать изменения:
  - `git -C ~/ai add -A && git -C ~/ai commit`
- Отправить изменения:
  - `git -C ~/ai push`
- Запустить Codex с локальным админским контекстом:
  - `~/.local/bin/codex-ai-admin`
  - `~/.local/bin/codex-ai-admin ai`
  - `~/.local/bin/codex-ai-admin dotfiles`
