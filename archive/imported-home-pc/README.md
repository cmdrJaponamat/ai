# Imported Home PC Archive

Этот каталог хранит материалы, которые были перенесены в `~/ai` с другой машины и не являются активным operational context для текущего ПК.

Содержимое:

- `actions.imported.log` — старый журнал действий
- `recovery/` — старые recovery-файлы
- `topical/` — тематические заметки
- `projects/` — legacy-скрипты и project-related остатки

Правило:

- Не использовать этот архив как активный источник правил по умолчанию.
- Открывать его только если нужен исторический контекст или ручной перенос старых идей.
