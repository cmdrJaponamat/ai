# Корпоративное оформление DOCX

Скрипт [format_corporate_docx.py](format_corporate_docx.py) оформляет текстовые
DOCX в корпоративном стиле АО «Аврора Логистика».

Он не меняет смысл документа и:

- задаёт Times New Roman 12;
- распознаёт нумерованные заголовки и приложения;
- включает перенос заголовка вместе с последующим текстом;
- оформляет таблицы, повторяет их шапку на новой странице и запрещает разрыв
  строки таблицы;
- переносит корпоративный фон, колонтитулы и параметры страницы из проверенного
  шаблона.

## Использование

\`\`\`bash
python3 ~/ai/scripts/format_corporate_docx.py \
  ~/work/Исходный_документ.docx \
  --output ~/work/Исходный_документ_корпоративный.docx \
  --brand-template ~/work/Регламент_учета_ИТ_оборудования_1_4_по_брендбуку.docx
\`\`\`

Исходный файл намеренно не перезаписывается. Так можно сначала проверить
результат и только затем заменить рабочую редакцию.

Для документа без корпоративного фона:

\`\`\`bash
python3 ~/ai/scripts/format_corporate_docx.py \
  ~/work/Исходный_документ.docx \
  --output ~/work/Исходный_документ_оформленный.docx \
  --no-brand
\`\`\`

## Границы автоматизации

Скрипт рассчитан на текстовые документы и таблицы. Он сохраняет текст,
таблицы, стили и разметку обычного односекционного DOCX. Для документов с
встроенными изображениями, сложными многостолбцовыми секциями или разными
ориентациями страниц итог нужно визуально проверить: таким документам может
потребоваться отдельное правило оформления.
