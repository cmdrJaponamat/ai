# PortalAL: витрина реквизитов компаний

## Выполнено

- В PortalAL добавлена страница `/company` в разделе «О компании».
- На странице опубликованы две карточки: АО «Аврора Логистика» и ООО
  «Аврора Лайн», с юридическими и банковскими реквизитами.
- Для каждой карточки доступны исходные форматы PDF и DOCX. DOCX для
  «Аврора Лайн» создан конвертацией предоставленного Word DOC; исходник не
  менялся.

## Проверка

- Production-контейнер запущен с образом
  `portal-al:1625ba689c2eed4d2c89faa9ead6a2373a20d659` и имеет статус
  `healthy`.
- `/api/health` вернул OK, все четыре URL в `/company-requisites/` отдают
  HTTP 200 с ожидаемыми MIME-типами PDF или DOCX.

## Откат

- Вернуть образ PortalAL на предыдущий `951caee58b2b8820772e403edec6680c19a53c95`
  через `PORTAL_IMAGE=portal-al:951caee58b2b8820772e403edec6680c19a53c95 docker compose up -d --no-build portal`
  из `/opt/portal-al`.
- Либо откатить commit PortalAL `1625ba6` и выполнить обычный deploy.
