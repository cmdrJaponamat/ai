# Черновик очереди `info` и ввод IMAP в PortalAL

Дата: 2026-11-12. Пользователь возобновил проект делопроизводителей и подтвердил: доступ к ящику `info` подготовлен, параметры он введёт сам через настройки портала; для операторов будет отдельная группа AD.

## Изменения

- В `assistent` обновлены ТЗ и проектная схема, коммиты `e6741c0`, `924ec3f`, `530c25c`. `info` — отдельный экземпляр общей очереди с подключаемым модулем корреспонденции; backend карточек пока не выбран.
- PortalAL `b735f20`: административный реестр очередей, начальные записи `it`, `legal` (active) и `info` (draft), создание черновиков, страница ввода IMAP для черновика. Новые таблицы `portal_service_queues` и `portal_queue_imap_sources` создаются при первом обращении к реестру. Пароль IMAP шифруется AES-256-GCM, API возвращает только `passwordConfigured`; `enabled=false` принудительно.
- На `10.78.3.149` в `/opt/portal-al/.env` создан `PORTAL_QUEUE_SECRET_KEY`, исходный файл сохранён как `/opt/portal-al/.env.before-info-queue-20261112`. Значение ключа не записывалось в лог и не передавалось в чат. Для расшифровки будущих сохранённых паролей ключ нужно сохранять в резервных копиях.
- AD-группа `App-Portal-Info-Operators` пока только предложена по шаблону; фактическая группа и DN не созданы и не подключены. Почтовый опрос и worker не запущены.

## Проверка

- Локально: `npm run build`, 3 профильных теста (реестр, ACL, шифрование), синтаксис Node и проверка diff прошли.
- CI и CD `b735f20` успешны. Production `portal-al:b735f20...` healthy, `/api/health` HTTP 200. Прямое чтение реестра из контейнера вернуло `it=active/hesk`, `legal=active/hesk`, `info=draft/unbound`. Настройки `info` пустые, `enabled=false`, пароль ещё не сохранён. Наличие 64-символьного ключа в контейнере проверено без вывода его значения.

## Откат

- Портал: `git revert b735f20` в PortalAL и штатный CD либо откат образа по штатной процедуре. Действующие маршруты ИТ и юристов этот коммит не меняет.
- Ключ: после отката кода и до появления сохранённых IMAP-паролей можно восстановить `/opt/portal-al/.env.before-info-queue-20261112`; после сохранения пароля ключ нельзя удалять без повторного ввода пароля.
- Таблицы реестра можно оставить: они не влияют на HESK. При необходимости удалять их только после проверки, что в `portal_queue_imap_sources` нет нужных настроек.
- Перезагрузка ОС не нужна. Портал пересоздаётся штатным CD; браузеру достаточно обновления страницы.
