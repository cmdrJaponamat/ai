# Индивидуальные колонки статусов очередей PortalAL

Дата: 2026-11-13. Запрос: администратор настраивает число, имена, порядок и цвета статусов отдельно для каждой очереди; канбан следует настройке.

Изменено: в PortalAL создана таблица `portal_queue_board_configs` с ключом `queue_id`, API чтения для роли своей очереди и записи для администратора. В настройках очередей добавлен раздел «Статусы», также для новых очередей реестра. Доски ИТ, юристов и info, их сводки и карточки читают конфигурацию выбранной очереди. У info фактическая стадия выводится из состояния письма, решения и результата отправки. Настройка колонок не меняет переходы HESK и действия над письмами.

Проверка: локально `npm test` (37 тестов), `npm run build`, `git diff --check`. CI и production deploy успешны (GitHub Actions 43377256580/43377256612). Образ `daf7fbe` в контейнере `portal-al` имеет состояние `healthy`. Прямое чтение конфигураций в рабочем контейнере: `it` 6/6 состояний, `legal` 6/6, `info` 8/8, у всех версия 1; другие настройки очередей не менялись.

Откат: вернуть предыдущий образ PortalAL; новую таблицу можно оставить, она не используется старым кодом. Перезапуск приложения требуется при развёртывании; relogin и reboot не нужны.
