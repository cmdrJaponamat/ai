# Расширение F: на ВМ 1C-WinSrv2019

Дата: 2026-11-15. Статус: выполнено, проверено через гостевой агент.

## Цель и исходное состояние

По запросу пользователя добавить к F: около 100 ГиБ уже выделенного, но не размеченного пространства. Целевой сервер: ВМ 121 `1C-WinSrv2019` на `spb-pve2`. Изменение выполнять через PVE QEMU Guest Agent в Windows, без изменения виртуального диска в PVE.

Связка: F: (`1CBKP`, NTFS, Healthy) = диск Windows 0, раздел 1 = `virtio0` PVE (`lvm_pathb:vm-121-disk-3`, 1300G). Стиль разделов MBR. Перед изменением размер диска 1 395 864 371 200 Б, раздела 1 288 487 043 072 Б (1200 ГиБ), свободно на томе 41 111 552 Б. `Get-PartitionSupportedSize` показывает максимум 1 395 862 274 048 Б. Пользователь подтвердил использование этих 100 ГиБ.

## Процедура

1. Перед командой повторно проверить VMID, диск, раздел, метку, NTFS, Healthy и исходные размеры.
2. Через гостевой агент выполнить `Resize-Partition -DiskNumber 0 -PartitionNumber 1 -Size 1395862274048`.
3. Через агент повторно проверить размер F:, свободное место и состояние тома.

Перезагрузка для онлайн-расширения NTFS не предполагается. Откат уменьшением раздела не выполнять автоматически: перед обратным изменением проверить размещение данных и доступную резервную копию. При повреждении файловой системы восстановление из резервной копии; при проблеме с монтированием — диагностика Windows/PVE без изменения других виртуальных дисков.

## Результат

Команда завершилась с кодом 0. После расширения размер раздела 1 395 862 274 048 Б (около 1300 ГиБ), размер тома 1 395 862 269 952 Б, свободно 107 413 065 728 Б (около 100 ГиБ). Метка `1CBKP`, файловая система NTFS, состояние Healthy. Размер виртуального диска PVE не менялся; перезагрузка не потребовалась.
