# Согласование домашнего и рабочего ноутбуков

Дата: 2026-10-05. Статус: архитектурная рекомендация, изменений в системе нет.

## Задача

Пользователь хочет одинаковое рабочее окружение на двух ноутбуках с Arch/Niri, возможность автономной работы и доступа к другой машине, несмотря на разные мониторы.

## Выводы

- Текущий `~/dotfiles` уже содержит `bootstrap.sh`, manifest и переносимые конфиги. Это подходящий источник истины для оболочки, UI и набора пакетов; аппаратные и мониторные параметры нужно отделить по машинам.
- Рабочие файлы и заметки можно синхронизировать выборочно через Syncthing: работа без сети сохраняется, при подключении файлы сходятся; одновременные правки одного файла требуют ручного разрешения конфликта. Включить историю версий и резервное копирование.
- Код и проектные конфиги вести через Git; не синхронизировать целиком `$HOME`, системные каталоги, базы, кэши, активные профили приложений и секреты.
- Удалённый терминал возможен через SSH/tmux в разрешённой сети/VPN. Для графического доступа проверить отдельным пилотом Sunshine/Moonlight на Niri: поддержку захвата, ввода, переключения мониторов и разрешений. Удалённая машина должна быть включена; корпоративные правила могут запрещать подключение.
- Точное состояние процессов и окон между двумя локальными ОС автоматически не переносится. Для двух рабочих мест рекомендуется гибрид: локальные окружения + выборочная синхронизация + удалённый доступ по необходимости.

## Проверка

Проверено по текущему recovery `~/dotfiles/.ai-recovery.md` и официальной документации Syncthing, Niri, Sunshine. Практический тест на рабочем ноутбуке не выполнялся.
