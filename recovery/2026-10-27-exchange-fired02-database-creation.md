# Создание DB-FIRED-02

Дата: 2026-10-27 (MSK)  
Объект: `DB-FIRED-02`, Exchange DAG SPB-MX4/SPB-MX3.

## Цель

Создать новую рабочую базу для ручного заполнения отключёнными сотрудниками,
использовав освобождённые после DB-FIRED-01 тома без изменения их разметки.

## Конфигурация

- Активная копия: SPB-MX4, `W:\DB-FIRED-02\DB-FIRED-02.edb`;
- журналы активной копии: `X:\DB-FIRED-02\Logs`;
- пассивная копия: SPB-MX3, activation preference 2, те же буквы томов и
  относительные пути;
- `MailboxRetention=30` дней, `DeletedItemRetention=14` дней;
- circular logging выключен;
- `IsExcludedFromProvisioning=True`: автоматическое размещение новых ящиков
  в этой базе запрещено.

## Результат

- MX4: `Mounted`, Copy/Replay queues = 0.
- MX3: `Healthy`, Copy/Replay queues = 0.
- Подключённых ящиков на момент создания нет.
- Перезапуск Exchange services не выполнялся: общие предупреждения cmdlet при
  создании базы/копии не потребовали его, база смонтировалась и репликация
  сразу стала Healthy.

## Backup и откат

Тома W:/X: входят в ежедневный `bkp_exchange_dag02`; первая успешная точка
после появления данных защитит DB-FIRED-02. Отдельное cold-job
`bkp_exchange_fired01_cold` для новой базы не запускать: оно хранит старую
цепочку холодного хранения. До заполнения откат прост: удалить пассивную
копию, объект базы и только эти два новых каталога.
