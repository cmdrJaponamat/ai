# Изменяемая ширина карточки и предпросмотра info

Дата: 2026-11-13. Пользователь обнаружил, что панели корреспонденции не растягиваются, в отличие от HESK.

Изменение: PortalAL получил ручки изменения ширины карточки и панели предпросмотра вложения. Ширина ограничивается доступным экраном; при открытии предпросмотра карточка сужается при необходимости. При ширине окна до 1024 px предпросмотр показывается отдельной панелью без ручек, чтобы две панели не перекрывались. Данные и backend не менялись.

Дополнение 2026-11-13: изменение ширины вынесено в общий `useQueuePanelLayout` для карточек HESK (ИТ, юристы) и info; адаптивные правила также общие. Отдельно для info добавлен маршрут скачивания каждого вложения из оригинала письма по IMAP UID и индексу, независимо от возможности предпросмотра. В образ добавлен `antiword` для извлечения текста из старых файлов `.doc`; существующие карточки нужно повторно разобрать кнопкой администратора, чтобы обновить рекомендацию и метаданные вложений.

Проверка: локально `npm run build`, `npm test` (43 теста), Python unittest (7 тестов), `git diff --check`. CI `43405630321` и production deployment `43405630482` завершились успешно. Рабочий контейнер `portal-al:503347e` в состоянии `healthy`, `/usr/bin/antiword` присутствует. Визуальное перетаскивание и скачивание реального файла в браузере оператора требуют приёмки.
